# Setting up your authenticator (two-factor)

Once this is set up, the dashboard asks for a 6-digit code from your phone before it
sends a broadcast to your preorder customers or cancels a Lulu print order. Someone
who gets hold of your password still cannot do either of those things.

Nothing changes until you finish these steps. Until then, broadcasts and cancels
work exactly as they do now, and the dashboard shows a reminder to set this up.

## What you need

- Your phone
- An authenticator app. Any of these work:
  - Google Authenticator
  - Microsoft Authenticator
  - 1Password
  - Authy

## Steps

1. Install one of the apps above on your phone, if you do not have one already.
2. On your computer, sign in and open **edeninstitute.health/founder**.
3. Click the **Security** tab.
4. Click **Set up authenticator**. A QR code and a long key appear.
5. In the app on your phone, choose to add an account, then scan the QR code.
6. The app now shows a 6-digit code that changes every 30 seconds. Type the code
   you see into the box on the dashboard and click **Confirm**.
7. You should see: "Authenticator set up. You will be asked for a code before
   sending broadcasts or cancelling orders."

## Keep a backup

The long key shown under the QR code is your backup. Before you click Confirm,
copy it into your password manager (for example as a note on your Eden Institute
login). If you lose or replace your phone, you can type that key into an
authenticator app on the new phone and get your codes back.

If you use 1Password as your authenticator, the backup is already kept for you
inside 1Password.

## Using it

- When you send a broadcast or cancel an order, a box asks you to "Enter the
  6-digit code from your authenticator app". Open the app, type the current code,
  and click Confirm. The action then goes ahead.
- You will not be asked again for the rest of that sign-in.
- If a code does not work, wait for the app to show a fresh one and try again.
  Codes only last about 30 seconds.

## If something goes wrong

- If you close the setup screen before typing a code, nothing was switched on.
  Just click **Set up authenticator** again and start over.
- If you have lost both your phone and the backup key, ask for help to remove the
  authenticator from your account. Do not create a new account.
